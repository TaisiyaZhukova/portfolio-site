# Паттерны проектирования (лабораторная работа)

**Описание:**  
Реализация паттерна проектирования Decorator на Python с использованием API Центрального Банка РФ. Приложение получает данные о курсах валют и динамически преобразует их в различные форматы представления: JSON, YAML и CSV. Также реализовано сохранение результатов в файлы и покрытие функциональности автоматическими тестами.
