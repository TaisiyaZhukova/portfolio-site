# Two Sum (сумма двух чисел)

**Семестр:** 3  
**Тип:** алгоритмическая задача

**Описание:**  
Реализация классической задачи: найти два числа в массиве, которые в сумме дают заданное значение. Используется хеш-таблица для оптимального поиска за O(n).
