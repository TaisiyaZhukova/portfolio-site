# Two Sum (сумма двух чисел)

**Описание:**  
Реализация алгоритма поиска двух чисел в массиве, сумма которых равна заданному значению. Проект включает решение задачи на Python с использованием списков и встроенных методов, а также набор unit-тестов для проверки корректности работы алгоритма на различных входных данных, включая повторяющиеся и отрицательные числа.
