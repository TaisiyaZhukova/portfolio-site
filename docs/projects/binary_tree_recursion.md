# Бинарное дерево. Рекурсия

**Описание:**  
Реализация бинарного дерева на Python с использованием рекурсии. Программа генерирует дерево заданной высоты в виде вложенной структуры словарей, поддерживает вывод древовидной структуры в консоль и включает набор unit-тестов для проверки корректности построения дерева и вычисления дочерних узлов.
