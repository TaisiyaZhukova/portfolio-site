# Шаблон «Одиночка» (Singleton)

**Описание:**  
Проект по работе с API Центрального Банка РФ и XML-данными с реализацией паттерна Singleton через метакласс Python. Программа получает курсы валют, обрабатывает XML-ответы, ограничивает частоту запросов к серверу и визуализирует данные с помощью графиков matplotlib.
