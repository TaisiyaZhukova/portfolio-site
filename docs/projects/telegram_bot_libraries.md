# Телеграм-бот для библиотек Петроградской стороны

**Описание:**  
Командный проект по разработке Telegram-бота для библиотек Петроградского района. Бот предоставляет информацию о книгах и библиотечных ресурсах, а также использует автоматический парсинг каталога библиотеки для обновления базы данных. В рамках проекта была реализована система обработки данных, проверки дубликатов и взаимодействия с базой данных PostgreSQL.
