# Доклад про паттерн Observer

**Описание:**  
Исследовательская работа и практическая реализация паттерна проектирования Observer (Наблюдатель) на Python. В рамках проекта был разработан пример системы уведомлений для Telegram-бота библиотеки с поддержкой подписки пользователей на книги и автоматической отправкой уведомлений при изменении состояния объекта.
