# Основные концепции ООП на Python

**Описание:**  
Командная учебная работа, посвящённая основным концепциям объектно-ориентированного программирования. В рамках проекта участники команды исследовали различные принципы ООП и подготовили практические примеры их реализации на разных языках программирования.
Моя часть проекта была посвящена принципу инкапсуляции. Были рассмотрены способы ограничения доступа к данным в Python и C, использование скрытых атрибутов, property, а также реализация методов для безопасной работы с внутренним состоянием объекта на примере банковского счёта.
