# Вычисление деления (с обработкой ошибок)

**Описание:**  
Программа для выполнения деления чисел с поддержкой обработки исключений и чтением параметров из конфигурационного файла. Реализована проверка корректности входных данных, обработка деления на ноль и валидация точности вычислений. Для тестирования функциональности использованы unit-тесты, покрывающие как корректные сценарии работы, так и возможные ошибки.
