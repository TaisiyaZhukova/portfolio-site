# Итераторы, генераторы, сопрограммы

**Описание:**  
Проект, посвящённый работе с итераторами, генераторами и сопрограммами в Python. Реализованы пользовательские итераторы для фильтрации чисел Фибоначчи из списка, а также сопрограмма для генерации последовательности Фибоначчи с использованием механизма send(). В проекте использованы аннотации типов и автоматические тесты для проверки корректности работы.
