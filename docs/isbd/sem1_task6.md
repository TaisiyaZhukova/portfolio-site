# Задание №6. Нормализация реляционных баз данных

**Тип:** самостоятельная работа (четыре блока заданий).

Содержит инвариантную и вариативную части по темам:

- Обобщённая архитектура баз данных.

- Этапы проектирования БД, модели данных.

- Реляционная модель данных, ограничения, операции реляционной алгебры.

- Нормализация реляционных БД.

**Выполненные работы включают**

- Заполнение таблиц по типам данных и моделям данных.

- Презентации о производителях СУБД и этапах развития СУБД.

- Развёртывание СУБД с помощью Docker (вариативная часть).

- Проектирование реляционной модели по описанию предметной области.

- Приведение таблиц к 3НФ и написание SQL-запросов.
