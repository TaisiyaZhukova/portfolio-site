## Шаг 1. Создание базы данных и заполнение таблицы для исследования динамической типизации

### Цель

Изучить поведение SQLite при сохранении данных различных типов.

### Используемые средства

* Python 3.12;

* sqlite3;

* DB Browser for SQLite (для просмотра результатов).

### Необходимый код

```python
import sqlite3

con = sqlite3.connect("lab.sqlite")
cur = con.cursor()

cur.execute("""
CREATE TABLE products(
    id INTEGER PRIMARY KEY,
    quantity INTEGER,
    price REAL,
    code TEXT
)
""")

rows = [
    (10, 15.5, "A101"),
    ("25", 20.7, "B202"),
    (8.9, "30.5", 100),
    ("abc", 45, "C303"),
    (None, None, None)
]

cur.executemany(
    "INSERT INTO products(quantity, price, code) VALUES (?, ?, ?)",
    rows
)

con.commit()
con.close()
```

### Количество записей

5 записей.

### Измерение времени

Не требуется.

### Результат

Создана база данных `lab.sqlite`, содержащая таблицу `products`.

### Представление результата

* файл `lab.sqlite`;

* листинг программы;

* скриншот таблицы в DB Browser for SQLite.
