# Задание №1. Создание простой БД

**Цель:** познакомиться с интерфейсом MySQL Workbench, создать базу данных `simpledb`, таблицы `users` и `resume`, освоить базовые операции вставки, обновления и экспорта данных.

**Краткое описание работы**
- Изучение главного окна и панели управления MySQL Workbench.
- Создание базы данных `simpledb` с кодировкой UTF-8.
- Создание таблицы `users` с полями `id`, `name`, `email`, `gender`, `bday`, `postal_code`, `rating`, `created`.
- Ручное добавление записей и выполнение SQL-запросов `INSERT`.
- Изменение структуры таблицы (добавление столбцов, настройка `ENUM`, `TIMESTAMP` с `CURRENT_TIMESTAMP()`).
- Создание таблицы `resume` с внешним ключом, связывающим её с `users` (каскадное удаление/обновление).
- Экспорт данных в `.sql`-файл и анализ синтаксиса.

**Основные навыки**
- Работа с визуальным конструктором таблиц в MySQL Workbench.
- Понимание типов данных (`INT`, `VARCHAR`, `ENUM`, `DATE`, `TIMESTAMP`, `TEXT`).
- Использование внешних ключей и каскадных операций.
- Генерация SQL-скриптов из графического интерфейса.
