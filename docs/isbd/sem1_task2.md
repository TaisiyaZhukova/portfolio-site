# Задание №2. Сохранение целостности. Forward engineering

**Цель:** освоить инструмент проектирования EER-диаграмм в MySQL Workbench, научиться строить связи между таблицами и выполнять прямое проектирование (forward engineering) для автоматической генерации базы данных.

**Основные этапы**

- Анализ готовой EER-модели `sakila_full` (из комплекта примеров Workbench).

- Изучение типов связей: `1:1`, `1:N`, `N:M`, идентифицирующая/неидентифицирующая.

- Понятие первичного и внешнего ключа.

- Создание собственной EER-диаграммы по тексту предметной области из статьи (магазины, продукты, заказы, доставки) с учётом найденных неточностей и исправлений.

- Экспорт модели в изображение и SQL-скрипт.

- Выполнение **Database → Forward Engineer** для развёртывания спроектированной БД на сервере.

- Тестирование целостности: добавление и удаление связанных данных, анализ поведения каскадных операций.

**Чему научились**

- Проектировать реляционную схему визуально.

- Понимать, как связи влияют на целостность данных.

- Автоматически генерировать рабочую БД из модели.
