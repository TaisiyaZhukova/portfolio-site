# Лабораторная работа №6

**Цель:** реализовать реляционную модель данных в MySQL Workbench на основе предложенной предметной области, а также выполнить вариативную часть (анализ избыточности БД или выделение сущностей и связей).

**Инвариантная часть**

- Создание таблиц в MySQL Workbench, отображающих связи между сущностями.

- Определение потенциальных ключей и условий проверки атрибутов.

- Работа с приложенным описанием предметной области и заданиями.

**Вариативная часть (один вариант на выбор)**

- *Вариант 1.* Проанализировать информацию по избыточности баз данных, привести примеры неверного логического проектирования и предложить алгоритм устранения недостатков.

- *Вариант 2.* На основе предметной области выделить сущности и отобразить связи между ними.

**Дополнительно:** в работе рассматривается развёртывание СУБД PHPMyAdmin через Docker (в том числе с использованием docker-compose).
