# Задание №3. Решение задач реляционной алгебры

**Цель:** применить операции реляционной алгебры (выборка, проекция, соединение, агрегация) для получения требуемой информации из заданной предметной области.

**Решаемые задачи**
1. Определить адреса клиентов, заказывавших игры с доставкой.
2. Определить название и производителя игры, в которую можно играть самой большой компанией.
3. Определить табельный номер сотрудника, ответственного только за один заказ на текущий момент.

Ход решения оформлен в виде текстового документа с формулами и пояснениями.

**Ссылка на решение:**  
[Открыть Google Документ](https://docs.google.com/document/d/1QA-AdeaY9_jWpkcW5CzIYDrOaVk4g6J_WSM10hZoopY/edit?usp=sharing)

**Ключевые операции**
- Проекция (`π`), выборка (`σ`), переименование (`ρ`).
- Естественное соединение (`⋈`).
- Использование агрегатных функций и группировки для поиска максимума/подсчёта.
