# Задание №4. Решение задач реляционной алгебры

**Цель:** аналогично заданию №3, но для другого набора запросов в той же предметной области.

**Решаемые задачи**
1. Определить имена и телефоны клиентов, заказ которых содержит не менее двух игр с разными названиями.
2. Найти табельный номер сотрудника, оформившего заказ, включающий игру с минимальным возрастом игроков 12 лет.
3. Найти фамилии и имена клиентов, купивших игры с минимальным количеством игроков 2, а максимальным — 6.

**Ссылка на решение:**  
[Открыть Google Документ](https://docs.google.com/document/d/1AuZW2Id6_qdfMLg6IA_o4CIw4IfYuWM1N3dYlVOmORs/edit?usp=sharing)

**Применяемые методы**
- Декартово произведение и фильтрация.
- Агрегация с условием `HAVING`.
- Комбинация нескольких операций для многошаговых запросов.
