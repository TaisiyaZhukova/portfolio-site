# Задание №5. Проектирование реляционной БД (НФБК)

**Цель:** на основе текстового описания предметной области спроектировать базу данных, все отношения которой находятся в нормальной форме Бойса–Кодда (НФБК).

**Предметная область:** учёт жёстких дисков (HDD) в организации.  
Атрибуты: производитель, его сайт, модель диска, объём, скорость вращения, интерфейс, серийный номер экземпляра, дата покупки, дата выхода из строя, комментарий.

**Шаги выполнения**

1. Построение одного универсального отношения со всеми атрибутами.

2. Декомпозиция до 3НФ, выявление функциональных зависимостей.

3. Определение первичных ключей для каждого отношения.

4. Проверка, что детерминанты всех ФЗ являются потенциальными ключами (требование НФБК).
